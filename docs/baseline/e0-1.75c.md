# E0 — baza pomiarowa: Waveshare ESP32-S3-Touch-AMOLED-1.75C

**Status: BLOCKED.** Płytka nie była podłączona w czasie sesji 2026-11-25. Na liście `/dev/serial/by-id` była tylko jednostka USB Serial/JTAG 1.85B (`28:84:85:87:98:7C`). Zgodnie z zasadami zadania jej części nie próbowano dalej.

| Pozycja | Status | Dowód |
|---|---|---|
| Kompilacja Xtensa, profil `rep` (z RP1 FSBENCH/HOME) | PASS (tylko kompilacja) | `tools/ci/build_firmware.sh waveshare_s3_touch_amoled_1_75c rep`, 0 ostrzeżeń; log `build-ci/e0-build-waveshare_s3_touch_amoled_1_75c.out` |
| Flash, wszystkie scenariusze E0, LittleFS + SHA-256, light sleep | BLOCKED | płytka niepodłączona |
| Prąd, dotyk palcem, obraz, słyszalność, chwila wake | PENDING | jak dla 1.85B, [e0-1.85b.md](e0-1.85b.md) §5 |

Kompilacja nie jest walidacją sprzętową.

Aby zebrać bazę, podłącz płytkę przez USB (złącze USB Serial/JTAG) i uruchom jedno polecenie z katalogu repozytorium:

```bash
python3 tools/hardware_validation/e0_board.py --board 1.75c
```

Polecenie wykonuje kolejno:
1. buduje obraz CI `rep` dla 1.75C z bieżącego commita (`tools/ci/build_firmware.sh`; środowisko ESP-IDF v6.1 ładuje samo, gdy `idf.py` nie jest w PATH);
2. znajduje płytkę: jedyną jednostkę Espressif USB Serial/JTAG albo, przy kilku, tę, której firmware zgłasza 1.75C (RG1 BATTERY lub RT1 GET `NO_RTC`);
3. wgrywa obraz przez OTA (`--ota`, RO1) i uruchamia `run_e0.py --light-sleep`;
4. uruchamia `run_e0_followup.py` i `run_e0_stall.py` bez drugiego OTA.

Raporty trafiają do `build-ci/e0/1.75c-<UTC>/{base,followup,stall}`. Wynik końcowy to PASS, FAIL albo BLOCKED.

Warianty:
- Gdy podłączonych jest kilka płytek albo wykrycie zawiedzie, podaj numer seryjny USB (MAC) z `ls /dev/serial/by-id`: `--serial <MAC>`. Zamiast niego możesz podać pełną ścieżkę: `--port /dev/serial/by-id/...`.
- `--no-build` używa obrazu już zbudowanego w `build-ci/waveshare_s3_touch_amoled_1_75c-rep`.
- `--only base|followup|stall` ogranicza przebieg.

Warunki wstępne:
- OTA działa przez RO1, więc na płytce musi już działać firmware Roundie z RO1. Tak jest dla obrazów `rep` od M8.
- Płytka z firmware fabrycznym Waveshare albo bez firmware wymaga jednorazowego wgrania przez USB: `idf.py -B build-ci/waveshare_s3_touch_amoled_1_75c-rep flash` po zbudowaniu. Runner tego nie robi, bo pierwszy flash zapisuje też tablicę partycji.
- Nic nie kasuje Flash, NVS ani LittleFS.

Obsługa 1.75C w runnerze (A2, sprawdzone tylko testami hosta):
- RG1 BATTERY zwraca nazwę płytki i dane AXP2101. Runner sprawdza tożsamość płytki i zapisuje kontekst zasilania.
- Kontekst ekranu zapisuje panel 466×466 z kanwą 360×360 skalowaną w górę.
- Stan BQ27220 (`RG1 STATUS`) runner odczytuje tylko na 1.85B, bo 1.75C tego układu nie ma.
- Jak scenariusze, które zakładają zewnętrzny RTC, zachowają się na płytce z `NO_RTC`, nie sprawdzono na urządzeniu. Wyniki tych pozycji trzeba przejrzeć w raporcie.
